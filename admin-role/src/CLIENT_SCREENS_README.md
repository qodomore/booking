# Клиентские экраны - Документация

## Обзор

Добавлены новые клиентские экраны для Telegram мини-приложения, которые позволяют конечным пользователям просматривать информацию об организациях и мастерах, а также записываться на услуги.

## Экраны

### 1. OrganizationScreen
**Путь:** `/components/OrganizationScreen.tsx`

Экран организации с полной информацией о бизнесе.

**Компоненты:**
- `OrgHeader` - Карусель медиа (16:9), название, рейтинг, описание, адрес, контакты, часы работы
- `OrgServiceList` - Список всех доступных услуг организации

**Основные функции:**
- Карусель медиа с изображениями организации
- Отображение рейтинга и отзывов
- Полная контактная информация (адрес, телефон, email)
- График работы по дням недели
- Список всех услуг с возможностью записи
- Кнопка "Записаться" для начала процесса бронирования

**Props:**
- `organizationId?: string` - ID организации
- `isEnabled?: boolean` - Флаг активности экрана (из настроек бизнеса)
- `onBack?: () => void` - Обработчик кнопки "Назад"
- `onServiceSelect?: (serviceId: string) => void` - Обработчик выбора услуги

### 2. MasterScreen
**Путь:** `/components/MasterScreen.tsx`

Экран мастера с профилем и доступными слотами для записи.

**Компоненты:**
- `MasterHeader` - Аватар (72px), имя, специализации (чипы), краткое био, рейтинг
- `MasterAvailability` - Блок ближайших доступных окон с группировкой по датам
- Список услуг мастера

**Основные функции:**
- Профиль мастера с аватаром и биографией
- Отображение специализаций в виде чипов
- Рейтинг и количество отзывов
- Ближайшие доступные слоты для записи (группировка по датам)
- Список услуг, которые предоставляет мастер
- Кнопка "Записаться к мастеру"

**Props:**
- `masterId?: string` - ID мастера
- `isEnabled?: boolean` - Флаг активности экрана (из настроек бизнеса)
- `onBack?: () => void` - Обработчик кнопки "Назад"
- `onServiceSelect?: (serviceId: string) => void` - Обработчик выбора услуги
- `onBooking?: (masterId: string, slotId: string) => void` - Обработчик бронирования конкретного слота

## Компоненты

### OrgHeader
**Путь:** `/components/OrgHeader.tsx`

Заголовок страницы организации с полной информацией.

**Особенности:**
- Карусель медиа с поддержкой нескольких изображений (соотношение 16:9)
- Рейтинг со звездами
- Адрес с кнопкой "Открыть на карте"
- Контактные данные (телефон, email)
- График работы по дням недели
- Кнопка "Записаться"

### OrgServiceList
**Путь:** `/components/OrgServiceList.tsx`

Список услуг организации.

**Особенности:**
- Карточки услуг с описанием и ценой
- Длительность услуги
- Возможность добавления ссылок на профили мастеров

### MasterHeader
**Путь:** `/components/MasterHeader.tsx`

Заголовок страницы мастера с профилем.

**Особенности:**
- Аватар 72x72px с fallback на инициалы
- Имя мастера
- Чипы со специализациями
- Краткая биография
- Рейтинг и отзывы
- Кнопка "Записаться к мастеру"

### MasterAvailability
**Путь:** `/components/MasterAvailability.tsx`

Блок доступных слотов для записи.

**Особенности:**
- Группировка слотов по датам
- Отображение дат: "Сегодня", "Завтра" или конкретная дата
- Сетка слотов по 3 в ряд
- Выбор слота с визуальной индикацией
- Пустое состояние при отсутствии доступных окон

## Навигация

### Источники навигации к экранам:

1. **Из карточки услуги:**
   - Ссылка "О мастере" → `MasterScreen`
   - Ссылка "Об организации" → `OrganizationScreen`

2. **Из поиска:**
   - Результаты поиска могут содержать deep-links к экранам

3. **Deep Links:**
   - `/organization/:id` → `OrganizationScreen`
   - `/master/:id` → `MasterScreen`

### Навигация из экранов:

**OrganizationScreen:**
- Кнопка "Записаться" → Выбор услуги → Выбор мастера → Выбор слота
- Клик на услугу → Переход к процессу бронирования

**MasterScreen:**
- Кнопка "Записаться к мастеру" → Выбор услуги → Выбор слота
- Клик на слот → Выбор услуги → Подтверждение
- Клик на услугу → Выбор слота → Подтверждение

## Флаги настроек бизнеса

Оба экрана поддерживают флаги включения/отключения:

### `isEnabled = true` (Экран активен)
Экран отображается с полной функциональностью.

### `isEnabled = false` (Экран скрыт)
Отображается stub-страница с сообщением:
- Иконка AlertCircle
- Заголовок "Страница недоступна"
- Описание "Эта страница отключена в настройках вашего бизнеса"
- Кнопка "Вернуться назад"

## Дизайн и стилизация

### Типографика
Используется шрифт **Kornilow** из `styles/globals.css`.

### Цветовая палитра
Используется текущая тема приложения (blue, pink, green, orange, purple).

### Сетка и отступы
- Горизонтальные отступы: `p-4` (16px)
- Вертикальные промежутки между секциями: `space-y-6` (24px)
- Отступы в карточках: `p-4` (16px)

### Компоненты
- Карточки: `clean-card` класс для непрозрачного фона
- Кнопки: `elegant-button` для gradient кнопок действия
- Адаптивность: Корректная работа на всех размерах устройств

## Демонстрация

### ClientExperienceDemo
**Путь:** `/components/ClientExperienceDemo.tsx`

Демо-экран, показывающий полный клиентский опыт с навигацией между экранами.

**Или запустить отдельные экраны:**
- "Экран организации (клиентский)"
- "Экран мастера (клиентский)"

**Путь:** `/components/ClientServiceCard.tsx`

Улучшенная карточка услуги с навигационными ссылками.

**Особенности:**
- Кнопки "О мастере" и "Об организации"
- Кнопка "Записаться" для начала бронирования
- Опциональное отображение навигационных ссылок

## Интеграция с App.tsx

Экраны добавлены в navigation stack в `App.tsx`:

```typescript
{currentScreen === 'organization' && (
  <OrganizationScreen 
    isEnabled={true}
    onBack={handleBackToPrevious}
    onServiceSelect={(serviceId) => {
      // Navigate to booking flow
    }}
  />
)}

{currentScreen === 'master' && (
  <MasterScreen 
    isEnabled={true}
    onBack={handleBackToPrevious}
    onServiceSelect={(serviceId) => {
      // Navigate to booking flow
    }}
    onBooking={(masterId, slotId) => {
      // Navigate to booking confirmation
    }}
  />
)}
```
