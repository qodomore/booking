## Навигация

### Точки входа
1. **Главное меню → Настройки → Демо и тестирование → Демо экраны**
   - Выбрать категорию "Клиентские"
   - Запустить нужный экран

2. **Из карточек услуг (ClientServiceCard)**
   - Кнопка "О мастере" → MasterScreen
   - Кнопка "Об организации" → OrganizationScreen

3. **Deep Links**
   - `/organization` → OrganizationScreen
   - `/master` → MasterScreen
   - `/client-experience` → ClientExperienceDemo

### Navigation Stack
Все экраны интегрированы в существующий navigation stack приложения с поддержкой:
- Кнопки "Назад"
- История навигации
- Правильное управление состоянием

## Флаги настроек бизнеса

Оба экрана (OrganizationScreen и MasterScreen) поддерживают флаги:

- `isEnabled = true` - Экран активен, показывается полная функциональность
- `isEnabled = false` - Показывается stub-страница "Страница недоступна"

## Тестирование

### Как протестировать
1. Запустить приложение
2. Перейти в Настройки
3. Нажать "Демо экраны" (или "Демо и тестирование")
4. Выбрать категорию "Клиентские"
5. Запустить любой экран:
   - **Клиентский опыт (полная демо)** - для полного тестирования навигации
   - **Экран организации (клиентский)** - для тестирования только OrganizationScreen
   - **Экран мастера (клиентский)** - для тестирования только MasterScreen

### Что проверить
- ✅ Корректное отображение на разных размерах экрана
- ✅ Карусель медиа на экране организации
- ✅ Список доступных слотов на экране мастера
- ✅ Навигация между экранами
- ✅ Кнопка "Назад" работает корректно
- ✅ Stub-состояние при `isEnabled = false`
- ✅ Типографика соответствует дизайн-системе
- ✅ Цвета соответствуют текущей теме
